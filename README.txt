IMC11203 – Data Science Methodology with Web Development
Website: CRISP-DM (HTML + CSS + Vanilla JS)
------------------------------------------------------

1) How to open/edit (Notepad++)
- Open Notepad++
- File > Open... and select index.html (or any page)
- Edit text inside <main> sections to personalize (name, student ID, etc.)
- Save (Ctrl+S)

2) How to run locally (no server needed)
- Go to the folder ds-methodology-site/
- Double-click index.html
- The site will open in your browser
- Use the top navigation to change pages

3) If you later add PHP (optional)
- This site is pure HTML/CSS/JS now.
- If you later add PHP, you must run it through a local server (e.g., XAMPP):
  - Put ds-methodology-site/ into xampp/htdocs/
  - Open http://localhost/ds-methodology-site/

4) Optional public hosting (extra marks)
Option A: GitHub Pages
- Create a GitHub repository (public)
- Upload the entire ds-methodology-site/ contents to the repo root
- Go to Settings > Pages
- Set Branch: main, Folder: /(root)
- Save, then GitHub gives you a live URL

Option B: Any static hosting
- Netlify / Vercel / etc. works because this is a static site.

5) How to zip for submission (no hosting)
- Right-click ds-methodology-site/ folder
- Send to > Compressed (zipped) folder
- Submit the .zip file
